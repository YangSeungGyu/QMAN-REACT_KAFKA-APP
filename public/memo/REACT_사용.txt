================[context Outlet안에서의 전역변수]================
context는 outlet에서 추가할 수 있다.

Outlet설정
  import { Outlet} from 'react-router-dom';
  const [contextMap, setContextMap] = useState({변수01: '값01',변수02: '값02'});
  <Outlet context={{contextMap,setContextMap}}/>  

context 사용 및 수정
  import { useOutletContext } from 'react-router-dom';
  const  { useOutletContext, setContextMap } = useOutletContext();
  수정 : setContextMap(prev => ({...prev, 변수02: '값03' }));

*주의 Outlet[1] > Outlet[2] > 컴포넌트 구조일 경우  컴포넌트에서는 Outlet[2]를 가져온다.
 - Outlet[1]로 올리는 경우 Outlet[2]가 선언된 곳에서 const rootCtx = useOutletContext();로
   Outlet[1]를 가져온 뒤 변수를 Outlet[2]로 넘겨야한다.
