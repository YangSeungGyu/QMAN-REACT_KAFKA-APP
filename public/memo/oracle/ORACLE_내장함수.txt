================[문자 관련 함수]================
1.LOWER,UPPER : 대소변환
  SELECT LOWER('AaAaAa'),UPPER('AaAaAa') FROM DUAL

2.INITCAP : 첫자를 대문자로 나머지를 소문자로 변환.
  SELECT INITCAP('aaaaaaa') FROM DUAL

3.SUBSTR : 문자열 자르기
  SELECT SUBSTR('123456789',2,5) FROM DUAL
  
  응용: 문자열 기준으로 찾아서 자르기 -- INSTR 문자 시작 위치 찾기
  SELECT 
  INSTR(VAL, 'c') AS START_IDX,(INSTR(VAL, 'f') - INSTR(VAL, 'c') + 1) AS LAST_IDX
  ,SUBSTR(VAL,INSTR(VAL, 'c'),(INSTR(VAL, 'f') - INSTR(VAL, 'c') + 1))
  FROM (SELECT 'abcdefg' AS VAL FROM DUAL) A

4.LENGTH : 컬럼 길이를 리턴
  SELECT LENGTH('123456789'),LENGTH('한글') FROM DUAL

5.LENGTHB: 컬럼의 바이트 길이를 리턴
SELECT LENGTHB('123456789'),LENGTHB('한글') FROM DUAL

6.ASCII: 문자에 해당하는 숫자(ASCII) 리턴.
select ASCII('  ')/*tab*/ FROM DUAL

7.CHR: 숫자에 해당하는 문자(ACSII)리턴.
select CHR(32)/*tab*/ FROM DUAL

8.LPAD/RPAD : 컬럼LENGTH를 총 N개로 설정하고 빈값은 왼쪽/오른쪽에서 문자를 채워넣음.
select LPAD('100',5,'0') FROM DUAL
select RPAD('100',5,'0') FROM DUAL

9.INSTR: 컬럼에서 문자가 최초로 나오는 자릿 수 찾기
SELECT  INSTR('ABCDEF','E') FROM DUAL



10.LTRIM : 문자와 다른 내용이 나올때까지 왼쪽에서 삭제
SELECT LTRIM('AA_AA_AA','A') FROM DUAL
SELECT RTRIM('AA_AA_AA','A') FROM DUAL


11.TRANSLATE : 컬럼 내용중 문자에 포함된 내용 매칭 치환 (대상값,바꿀값 개수가 같아야함, 나머진 공백치환)
SELECT TRANSLATE('AB_AB_BC_BC_AAA_BBB','AB','12') FROM DUAL


12.REPLACE : 문자 치환
SELECT REPLACE('AB_AB_AC_AC_AAA_BBB','AA','TEST') FROM DUAL

18.ABS : 절대값 리턴

================[분석용 함수]================
=============================================
================[RANK]================
설명 : 특정 컬럼을 기준으로 랭킹(순위)를 지정함.
사용 :
 SELECT
 RANK() OVER(ORDER BY 컬럼1) AS C1
 RANK() OVER(ORDER BY 컬럼1 DESC) AS C2
 FROM
 테이블
결과 : C1은 적은 값을 1위로 지정, C2는 많은값을 1위로 지정
       (같은 순위가 있는만큼 다음 순위에+됨 1,1,3,4)
================[DENSE_RANK]================
설명 : 특정 컬럼을 기준으로 랭킹(순위)를 지정함.
사용 :
 SELECT
 DENSE_RANK() OVER(ORDER BY 컬럼1) AS C1
 DENSE_RANK() OVER(ORDER BY 컬럼1 DESC) AS C2
 FROM
 테이블
결과 :(같은 순위가 있어도 순서대로 지정 1,1,2,3) 

================[PARTITION BY]================
설명 : 그룹 지정 후 총계 값을 그룹내에서 분석용 함수 사용시
사용:
 SELECT
 컬럼2,
 컬럼3,
 컬럼4,
 SUM(컬럼1),
 RANK() OVER (PARTITION BY DEPT_CODE ORDER BY SUM(컬럼1) DESC) AS C1
 FROM
 테이블1
 GROUP BY 컬럼2,컬럼3,컬럼4
결과: 그룹별로 순위가 메겨진다.
================[CUME_DIST]================
설명 : RANK와 비슷하며 순서를 0~1사이의 값으로 표기한다.

================[PERCENT_RANK]================
설명 : 0~1사이의 RANK에 맞게 구한다.(첫 값을 0으로 잡는다.)

================[NTILE(숫자값)]================
설명 : 전체 데이터 ROW를 숫자값 만큼 나눠서 ROW순서를 메긴다.

================[ROW_NUMBER()]================
설명 : PARTITION 내의 ROW들을 순서대로 일련번호 부여

================[UNBOUNDED PERCEDING]================
설명 : PARTITION 조건을 기준으로 이전 값들 더하여 출력
       (EX 조건1일때 100,100+250,350+50,400+20.. 조건 2일때 50,50+...)
사용:
 SELECT 
 SUM(컬럼1) OVER (PARTITION BY 조건컬럼 ORDER BY 조건컬럼 ROWS UNBOUNDED PERCEDING) AS C1
 FROM
 테이블1

================[UNBOUNDED FOLLOWING]================
설명 : UNBOUNDED PERCEDING 의 역순

================[10. .....]================
partition by 컬럼1 order by 컬럼1 rows between unbounded preceding and unbounded following
설명 : 컬럼1에 대하여 각 파티션에 대한 범위를 모두 포함한다.

================[FIRST_VALUE]================
설명 : 범위내의 가장 앞에 있는 값을 읽어옴
사용 : 
SELECT
FIRST_VALUE(컬럼1) OVER 
(PARTITION BY 컬럼2 ORDER BY 컬럼1 ROWS BETWEEN UNBOUNDED PRECEDING UNBOUNDED FOLLOWING) AS C1
FROM 테이블1
결과 : 컬럼2를 그룹 기준으로 그룹내의 가장 첫번째 값만 리턴한다.

================[LAST_VALUE]================
설명 : 가장 마지막 값을 읽어옴 (사용법은 FIRST_VALUE와 동일)

================[LAG]================
설명 : n개ROW 위의 컬럼값을 가져 온다.

사용 :
SELECT 
LAG(컬럼1,1) OVER (ORDER BY 컬럼2) AS C1
FROM 테이블1 
ORDER BY 컬럼2
결과 :컬럼2를 기준으로 1개 위의 컬럼 값을 가져옴.

================[LEAD]================
설명 : n개ROW 아래의 컬럼값을 가져 온다.(사용법 LAG와 동일)

================[ROLLUP]================
설명 : 소계의 총계를 구할때 사용

사용 :
SELECT
분류1컬럼,분류2컬럼,분류이름,SUM(값컬럼)
FROM
테이블1
GROUP BY ROLLUP(분류1컬럼,분류2컬럼,분류이름)
결과 : 분류 목차가 끝나면 분류2에대한 값 합계를 출력하고,
분류1에대한 목차가 끝나면 분류2에대한 값 합계를 출력한다.

================[CUBE]================
설명 : 소계의 총계를 구할때 사용하지만 출력 형태가 ROLLUP과 다르다.

사용 :
SELECT
분류1컬럼,분류2컬럼,SUM(값컬럼)
FROM
테이블1
GROUP BY CUBE(분류1컬럼,분류2컬럼)

결과 : 우선 기본 출력대로 출력 후 최종적으로 2차분류별 
합계를 내고 마지막에 1차분류의 합계를 출력.
