================[1.RANK]================
설명 : 특정 컬럼을 기준으로 랭킹(순위)를 지정함.
사용 :
 SELECT
 RANK() OVER(ORDER BY 컬럼1) AS C1
 RANK() OVER(ORDER BY 컬럼1 DESC) AS C2
 FROM
 테이블
결과 : C1은 적은 값을 1위로 지정, C2는 많은값을 1위로 지정
       (같은 순위가 있는만큼 다음 순위에+됨 1,1,3,4)
================[2.DENSE_RANK]================
설명 : 특정 컬럼을 기준으로 랭킹(순위)를 지정함.
사용 :
 SELECT
 DENSE_RANK() OVER(ORDER BY 컬럼1) AS C1
 DENSE_RANK() OVER(ORDER BY 컬럼1 DESC) AS C2
 FROM
 테이블
결과 :(같은 순위가 있어도 순서대로 지정 1,1,2,3) 

================[3.PARTITION BY]================
설명 : 그룹 지정 후 총계 값을 그룹내에서 분석용 함수 사용시
사용:
 SELECT
 컬럼2,
 컬럼3,
 컬럼4,
 SUM(컬럼1),
 RANK() OVER (PARTITION BY DEPT_CODE ORDER BY SUM(컬럼1) DESC) AS C1
 FROM
 테이블1
 GROUP BY 컬럼2,컬럼3,컬럼4
결과: 그룹별로 순위가 메겨진다.
================[4.CUME_DIST]================
설명 : RANK와 비슷하며 순서를 0~1사이의 값으로 표기한다.

================[5.PERCENT_RANK]================
설명 : 0~1사이의 RANK에 맞게 구한다.(첫 값을 0으로 잡는다.)

================[6.NTILE(숫자값)]================
설명 : 전체 데이터 ROW를 숫자값 만큼 나눠서 ROW순서를 메긴다.

================[7.ROW_NUMBER()]================
설명 : PARTITION 내의 ROW들을 순서대로 일련번호 부여

================[8.UNBOUNDED PERCEDING]================
설명 : PARTITION 조건을 기준으로 이전 값들 더하여 출력
       (EX 조건1일때 100,100+250,350+50,400+20.. 조건 2일때 50,50+...)
사용:
 SELECT 
 SUM(컬럼1) OVER (PARTITION BY 조건컬럼 ORDER BY 조건컬럼 ROWS UNBOUNDED PERCEDING) AS C1
 FROM
 테이블1

================[9.UNBOUNDED FOLLOWING]================
설명 : UNBOUNDED PERCEDING 의 역순

================[10. .....]================
partition by 컬럼1 order by 컬럼1 rows between unbounded preceding and unbounded following
설명 : 컬럼1에 대하여 각 파티션에 대한 범위를 모두 포함한다.

================[11.FIRST_VALUE]================
설명 : 범위내의 가장 앞에 있는 값을 읽어옴
사용 : 
SELECT
FIRST_VALUE(컬럼1) OVER 
(PARTITION BY 컬럼2 ORDER BY 컬럼1 ROWS BETWEEN UNBOUNDED PRECEDING UNBOUNDED FOLLOWING) AS C1
FROM 테이블1
결과 : 컬럼2를 그룹 기준으로 그룹내의 가장 첫번째 값만 리턴한다.

================[12.LAST_VALUE]================
설명 : 가장 마지막 값을 읽어옴 (사용법은 FIRST_VALUE와 동일)

================[13.LAG]================
설명 : n개ROW 위의 컬럼값을 가져 온다.

사용 :
SELECT 
LAG(컬럼1,1) OVER (ORDER BY 컬럼2) AS C1
FROM 테이블1 
ORDER BY 컬럼2
결과 :컬럼2를 기준으로 1개 위의 컬럼 값을 가져옴.

================[13.LEAD]================
설명 : n개ROW 아래의 컬럼값을 가져 온다.(사용법 LAG와 동일)

================[14.ROLLUP]================
설명 : 소계의 총계를 구할때 사용

사용 :
SELECT
분류1컬럼,분류2컬럼,분류이름,SUM(값컬럼)
FROM
테이블1
GROUP BY ROLLUP(분류1컬럼,분류2컬럼,분류이름)
결과 : 분류 목차가 끝나면 분류2에대한 값 합계를 출력하고,
분류1에대한 목차가 끝나면 분류2에대한 값 합계를 출력한다.

================[15.CUBE]================
설명 : 소계의 총계를 구할때 사용하지만 출력 형태가 ROLLUP과 다르다.

사용 :
SELECT
분류1컬럼,분류2컬럼,SUM(값컬럼)
FROM
테이블1
GROUP BY CUBE(분류1컬럼,분류2컬럼)

결과 : 우선 기본 출력대로 출력 후 최종적으로 2차분류별 
합계를 내고 마지막에 1차분류의 합계를 출력.
