================[arrow function, 변수 function 차이]================
const obj = {
  name: "test",
  handleClick: function() {
    console.log(this.name); //this는 obj
  }
};

const obj = {
  name: "test",
  handleClick: () => {
    console.log(this.name); //this는 obj가 아님
  }
};


또한 함수 내용이 1줄일 소괄호()를 치면 return과 동일
const test = () => {return '11'}
const test = () => ('11') 



================[useState 주의점]================
변수를 타 변수에 적용해서 사용하면 useState 속성을 잃어버리니 주의
