=================셋팅에 따른 설정=========================
01.main.jsx 에서 /store/store를 Provider로 감쌈

02.store.js에서 rootReducer store에 연결하고 rootSaga를 run (미들웨어에연결)

03.rootReducer.js에서는 모든reducer를 셋팅

04.rootSaga.js에 모든 saga 연결

05.각 saga에서는 slice와 api를 연결(slice에서 리듀서 생성)



개념:
Slice(상태관리설계도) : 결과를받을변수,상태값변수들과 + Reducer를 포함한 파일
Api : axios api요청을 함수로 분리(Saga에서 호출함)
Reducer(상태변경함수) : 각 비동기에 요청,결과에대한 함수.
Saga : Api와 Reducer함수를 요청별로 셋팅하여 Worker로 생성 후 takeLatest에 셋팅하여 Saga로 생성
 - takeLatest에 등록되면 Watcher에 등록되어 실시간 감지됨(동일요청 무시 마지막것만 실행)

=================saga사용=========================
설정파일 생성 및 연결 :
/features/경로에 postApi.js생성 :  api 호출작성
/features/경로에 postSlice.js생성 : 상태관리 변수 및 request,success,fial 함수 작성
/sagas/경로에 postSaga.js 생성 : slice,api등 여기서 셋팅 후 saga파일 생성
rootSaga.js에 saga 추가
rootReducer.js에 reducer추가
